# Converter Pro v4
All-in-one converter starter with server endpoints for:
- PDF -> Word
- Word/Excel/PowerPoint -> PDF
- Video -> MP3/WAV
- Audio -> MP3
- Image -> PNG/JPG/WEBP
- PDF Merge
- OCR -> TXT

## Install
Node.js 18+ is required.
Run `npm install` then `npm start`.

For real Office/PDF conversion install LibreOffice.
For video/audio install FFmpeg.
For OCR install Tesseract OCR and the language packs you need.

This is a starter production architecture; add authentication, rate limits, cloud storage, virus scanning and HTTPS before public deployment.
